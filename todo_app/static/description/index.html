Todo App - Task Management for Odoo ==================================== .. image:: https://img.shields.io/badge/license-LGPL--3-blue.svg :target: https://www.gnu.org/licenses/lgpl-3.0.html :alt: License: LGPL-3 .. image:: https://img.shields.io/badge/odoo-17.0-purple.svg :alt: Odoo Version A comprehensive task management solution for Odoo that helps you organize and track your daily tasks efficiently. Features -------- ✅ **Task Management** - Create and manage tasks with rich descriptions - Set priorities (Low, Normal, High, Urgent) - Track progress with percentage completion - Set deadlines and get overdue notifications 📂 **Organization** - Organize tasks by categories - Label tasks with customizable tags - Multi-company support 👁️ **Multiple Views** - Kanban board with drag & drop - List view with inline editing - Calendar view for deadline tracking - Graph and Pivot for analysis 👥 **Collaboration** - Assign tasks to team members - Activity scheduling and reminders - Chatter for task discussions - Email notifications 🔒 **Security** - User and Manager access levels - Users see only their own tasks - Managers have full access Screenshots ----------- .. image:: static/description/screenshot_kanban.png :alt: Kanban View .. image:: static/description/screenshot_form.png :alt: Task Form Installation ------------ 1. Download the module 2. Place it in your Odoo addons directory 3. Update the apps list 4. Install "Todo App" from the Apps menu Configuration ------------- 1. Go to Todo → Configuration 2. Create Categories and Tags 3. Assign user access rights Usage ----- 1. Navigate to the Todo menu 2. Click "Create" to add a new task 3. Fill in task details and save 4. Use the Kanban board to manage workflow Support ------- For support, please contact: support@digifact.com Changelog --------- **17.0.1.0.0** (Initial Release) - Task management with CRUD operations - Categories and Tags - Multiple views (Kanban, List, Calendar, Graph, Pivot) - User access control - Multi-company support - Chatter integration Credits ------- **Author:** DigiFact **Contributors:** - DigiFact Development Team **Maintainer:** DigiFact This module is maintained by DigiFact.
